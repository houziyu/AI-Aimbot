# Python 3.13 / Windows install set for AI-Aimbot
#
# Verified on Python 3.13.12 + Windows 10.0.26100 + RTX 4060.
#
# Install PyTorch FIRST, with the CUDA index matching your driver (cu128 shown here):
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#
# Then install this file (the "fast" main.py and "faster" main_onnx.py both work):
#   pip install -r requirements-py313.txt
#
# TensorRT is deliberately absent: there is no cp313 Windows wheel, so main_tensorrt.py
# cannot be used on 3.13. Use main.py or main_onnx.py instead.

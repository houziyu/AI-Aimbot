# 开发验证记录

验证日期：2026-11-12。

## 已执行

- Windows / Python 3.13 虚拟环境安装 `requirements.txt`，`pip check` 通过。
- `pytest tests -q`：15 项测试通过。涵盖坐标变换、NMS、目标保持/丢失、配置保存与校验、协议限速、在途推理取消、串口断开、设备拔出、截图异常、写入异常、窗口失焦暂停，以及 UI 导航、保存与快捷键边沿。
- 两个自带的 ONNX 半精度模型均在 CPU 上加载并完成推理。
- 从仓库自带的 Rust 样例图中取得人物检测结果。
- `tools/check_ui.py`：实际 Qt 控制台、参数页、日志页和小窗口截图检查通过。离屏渲染显式加载 Windows 中文字体。
- `tools/check_pipeline.py --simulate-focus`：临时显示仓库样例图，使用真实 Win32 客户区坐标、真实 MSS 截图和真实 ONNX 推理，输出到模拟串口。取得 1 个检测目标，并产生方向字节；关闭后不再输出，工作线程正常退出。

截图链路单次观测约 29 次/秒、识别约 21 ms。这只是本机一次样例检查，不是实际应用性能承诺。

## 未验证部分

- 自动启动的测试窗口未能取得 Windows 前台焦点，正常模式检查因此进入「等待目标窗口」；截图链路检查使用了 `--simulate-focus`。前台保护逻辑另有单元测试，真实用户切换窗口仍需在桌面上验证。
- 本轮没有向真实 ESP32 发送位移。真实蓝牙 HID 接收、方向步长、目标程序灵敏度和最终手感需要用户连接现有设备验证。
- 未安装和运行 DirectML / CUDA 后端。
- 固件无 HID 接收回执，无法验证端到端延迟或独立蓝牙断连检测。

## 复现

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe tools/check_ui.py
.\.venv\Scripts\python.exe tools/check_pipeline.py
```

最后一条会短暂打开测试窗口，模拟串口输出，不移动真实光标。应保持测试窗口前台；无法获得焦点的自动化环境可加 `--simulate-focus`，此参数只修改测试脚本的模拟行为，不修改主程序的前台保护。
